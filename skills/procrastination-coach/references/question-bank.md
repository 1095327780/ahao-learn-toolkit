# 问诊问题库

**用法**：一次只问一个。按顺序挑，问到能分流就停，不要把一组问题一起抛出。用户已经说过的不再问。问完一句，等他答，再决定下一句。

## 一、分流决策树

```
第 0 步：安全筛查（边听边看）
  ├─ 想死 / 伤害自己 / 活着没意思 → 立即停止效率辅导，referral.md 危机做法
  ├─ 两周以上大多数时候低落或提不起兴趣、睡眠食欲明显变、几乎什么都开不了头
  │     → referral.md（建议就医）；可以陪做一件极小的事，但不当成拖延问题处理
  └─ 都没有 → 第 1 步

第 1 步：在拖什么？（一句话）
第 2 步：“如果现在马上开始，你最不想面对的是什么？”

第 3 步：按回答分流（只选一个主路线），说出判断并问“对不对”
  A. 不知道从哪下手 / 太大了 / 想到就头大 / 一团乱
       → shrink-the-step.md（主）；说不出第一下 → next-physical-action.md
  B. 今天太累，明天 / 周末一口气搞定
       → planning-fallacy.md 点破一句 → if-then-and-woop.md（主）
  C. 停不下来 / 再刷一会儿 / 再看一集 / 该睡了还在玩手机
       → friction-and-temptation.md（主）＋ if-then-and-woop.md 停止信号
  D. 怕写不好 / 怕被骂 / 不够好不敢交 / 想一次弄完美
       → perfectionism-and-fear.md（主）＋ self-forgiveness.md；怕得强、久、泛化 → referral.md
  E. 我好废 / 又拖了 / 我就是懒
       → self-forgiveness.md 接住一两句，再回第 2 步
  F. 太无聊 / 没意义 / 烦 / 讨厌这活
       → mood-repair.md（主）＋ 诱惑捆绑 或 procrastination-equation.md 的价值旋钮
  G. 我不会 / 做不来 / 肯定搞不定
       → procrastination-equation.md 的期望旋钮
  H. 我一直截止前做，做得不差，也不难受
       → procrastination-equation.md 末节“先别治”；确认后不干预
  I. 事情太多，最难那件一直躲，其他事在做
       → structured-procrastination.md，或把最难那件也缩到一步
  J. 从小就这样，走神、丢三落四、什么都拖、换了方法也没用
       → 先帮当下这件，同时按 referral.md 提一句注意力评估

第 4 步：判断不了 → 再问一个问题（不是给一串办法）
  首选：“是不知道怎么做，还是知道怎么做、就是不想碰？”
  次选：“如果这件事今天一定得做完，你会先做哪一下？”

第 5 步：几种情况都有 → 先做用户最想解决的那个，其余记下来下次
```

## 二、四个旋钮的后台透镜（不对用户讲公式）

| 旋钮 | 拖延时听起来像 | 对应路线 |
|---|---|---|
| 期望低（觉得做不成） | “我不会”“肯定搞砸” | G、D |
| 价值低（过程难受、没意义） | “好无聊”“烦死了”“有什么用” | F |
| 冲动高（容易被拉走） | “刷着刷着就……”“停不下来” | C |
| 回报远（截止远、好处在以后） | “还早呢”“明天再说” | B、A |

## 三、问题库

**开场**
- 你现在在拖的是哪件事？一句话说就行。
- 如果现在马上开始，你最不想面对的是什么？
- 这件事拖了多久了？拖着的时候，你心里是什么感觉？（用来区分拖延和有意延后）

**安全（只在有信号时问）**
- 这种提不起劲的状态，是只对这件事，还是最近对很多事都这样？
- 这样有多久了？睡觉、吃饭还正常吗？
- 你现在安全吗？有没有想过伤害自己？（出现危险信号时）

**区分卡点**
- 是不知道怎么做，还是知道怎么做、就是不想碰？
- 一想到要开始，第一个冒出来的念头是什么？
- 如果这件事今天必须做完，你会先做哪一下？
- 一般是在哪一步卡住：开头、中间，还是快收尾的时候？
- 拖的时候你一般在做什么？（看诱惑是什么、是“停不下来”还是“躲”）

**说出那份难受（mood-repair）**
- 用一两个词说说现在的感觉：是烦、闷、怕、累，还是别的？
- 这份难受，是冲着这件事本身，还是冲着做完以后要面对的东西（被评价、被拒绝）？

**太大、太模糊（shrink-the-step / next-physical-action）**
- 是什么让这件事现在难做到？
- 这件事做完，具体是什么样子？
- 要到那一步，最开头那一下，手要做什么？
- 做这一下之前，你还需要先决定什么吗？
- 这一下两分钟能做完吗？
- 你每天必然会做的哪件事之后，接着做这一下最顺？

**明天再说（planning-fallacy / if-then）**
- 上一次你说“明天搞定”，第二天发生了什么？
- 明天这个时候，你大概是什么状态？会比现在轻松吗？
- 你以前做类似的事，实际花了多久？
- 明天你几点、在哪儿能坐下来？说个真做得到的。

**停不下来（friction-and-temptation）**
- 拖的时候，手最常去抓什么？
- 你是不想睡，还是不想停下手上的事？
- 手机充电线能放到卧室外面吗？
- 有没有一件你喜欢、又可以只在做这件事时才碰的东西？

**怕（perfectionism-and-fear）**
- 你担心的是做得不够好，还是担心别人怎么看？
- 这一版给谁看？他最低要看到什么？
- 有没有一种写法，是不会被任何人看到的？

**做不成（procrastination-equation 期望）**
- 你觉得自己能做成吗？卡在哪个不会的地方？
- 有没有一个别人做过的样子可以照着看？
- 身边谁会这个？

**自责（self-forgiveness）**
- 这几天你骂自己了吗？骂完更想做了吗？
- 如果你最好的朋友拖了这件事，跑来说“我好废”，你会怎么回他？

**落地**
- 打开它以后，你手做的第一下是什么？
- 你打算什么时候、在哪儿做这一下？
- 到时候最可能把你拉走的是什么？它出现了你打算怎么办？

**收口**
- 这一步你现在就能做吗？要不要再小一点？
- 做完以后，你打算怎么跟自己说一句“干得不错”？

**回访**
- 上次那一步做了吗？
- （做了）做的时候，比你想的难，还是容易？
- （没做）没做也没关系，是在哪一下卡住的？
- （连着几次没做）这件事你自己还想做吗？

## 四、不要问的问题

- “你为什么总是拖？”——像审问，答案只会是“因为我懒”。
- “你知道这件事很重要吧？”——他知道，问了只会更难受。
- 一次连问三个问题。
- 用户说“先这样”以后的任何追问。
