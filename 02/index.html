让 AI 考你，而不是替你总结

看得越顺，留下的越少。把 AI 从替你思考的拐杖，变成逼你思考的考官。

复制全文，连同学习材料一起发给 AI

适用于 Claude Code、Codex、Cursor 等 AI Agent。下载后解压至 Skill 目录，或将下方指令发送给 Agent 自动安装。

下载 thinking-coach.zip94.6 KB · 源文件在 GitHub / CNB

下载不了、也打不开 GitHub 时，把下面这段整段发给 agent，它会把全部 33 个文件逐字建好。

适用场景

刚读完一篇文章、一章书，或者看完一段课程，想确认自己是不是真的学会了。

使用方法

  1. 先自己把材料看一遍，再发提示词。不要先让 AI 总结。
  2. 回答时不看材料。想不起来也先猜一个，再看答案。
  3. 隔一两天，把上次答错的题发给 AI，让它换个场景再考一次。

想要一问一答、更完整的引导，可以用 skills/thinking-coach。
